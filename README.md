# Clash-RuleSet-Mod

```
├── rules/

│   │   ├── Custom.yaml        #   自定义个人规则
│   │   ├── ...
│   │
│   └── mrs/                   # 预编译 .mrs 规则集
│       └── Custom.mrs
│
└── readme.md
```
